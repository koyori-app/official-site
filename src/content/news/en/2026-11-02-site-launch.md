We launched the Koyori website, a single place to learn about every Koyori product.

The site introduces the four products we are currently building:

- **Koyori Task**: self-hostable task management for teams
- **Koyori VRT**: visual regression testing as a service, where reviewed screenshots become the next baseline
- **Koyori UI**: a component library generated from one Mitosis source into Vue and React packages
- **Koyori Arc**: a Gantt chart renderer with dependency arcs, written in Rust and compiled to Wasm

The site itself is [open source on GitHub](https://github.com/koyori-app/official-site). It is built with Astro and React and served from GitHub Pages. If you spot a typo or have a suggestion, open an issue or a pull request.
