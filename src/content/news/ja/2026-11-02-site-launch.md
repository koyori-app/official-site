Koyori のプロダクトをまとめて紹介する公式サイトを公開しました。

このサイトでは、現在開発している 4 つのプロダクトを紹介しています。

- **Koyori Task**: セルフホストできるチーム向けのタスク管理
- **Koyori VRT**: CI のスクリーンショットをレビューして baseline に育てる、ビジュアルリグレッションテストのサービス
- **Koyori UI**: Mitosis の単一ソースから Vue と React のコンポーネントを生成する UI ライブラリ
- **Koyori Arc**: Rust と Wasm で描く、依存関係つきのガントチャートレンダラー

サイト自体も [GitHub で公開](https://github.com/koyori-app/official-site)しています。Astro と React で作り、GitHub Pages で配信しています。誤字や改善点を見つけたら Issue や Pull Request でお知らせください。
